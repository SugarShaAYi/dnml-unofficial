基本的な書き方

  1. ・DNMLとは文章の中に"タグ"と呼ばれる命令 を書いてデジタル・ノベルを作成するための言語です。
    その文法はHTMLそっくりでホームページを作ったことのある人なら サンプルを一読するだけで書けるようになるでしょう。
    ・HTMLを知っているのなら以下の説明を見る必要は有りません。

  2. ・タグは一つの「タグ名」と、「キー」と「値」を一組とするオプション からなります。
    「値」は"(ダブルクォーテーション)で括ってください。

    <BACKGROUND SRC="title.bmp" FOLDER ="c:\">
    ----------- +++ ***********
    ↑タグ名　　↑キー　↑値

  3. ・「タグ名」と「キー」は大文字と小文字を区別しません。

    <BACKGROUND SRC="lvns3.pak\c0101.lf2">
    <Background Src="lvns3.pak\c0101.lf2">
    と は等しい。注意！「値」は区別します。

  4. ・オプションは前後しても構いません。

    <BACKGROUND SRC="titile.bmp" FOLDER ="c:\">
    <BACKGROUND FOLDER ="c:\" SRC="title.bmp" >
    とは等しい。

  5. ・半角スペースと改行は無視します。

    <　Background Src="title.bmp">
    < 　Background Src="title.bmp" >
    <　　　Background Src　=　　"title.bmp">
    < Background Src　=　"title.bmp" >
    <Background
    Src　=　"title.bmp"
    >

    以上五つすべて有効なDNML。

  6. ・一行にいくつでも自由に配置できます。

    せっかくだから、<W>この<FONT COLOR="#FF0000">
    赤い<FONT COLOR="#FFFFFF">扉を 選ぶぜ！

    HTMLと同じようにタグを自由に配置できます。

  7. ・ '<' と '>' を表示するには'&lt;'と'&gt;'を使います。
    また '&' と '"' を表示するには'&amp;'と'&quot;'が使えます。
    (普通にも表示できます。)
    行の先頭に' '(半角スペース)を表示するときには'&nbsp;'を使います。

    背景を表示するには&lt;BACKGROUND&gt;タグを使います。
    ↓
    背景を表示するには<BACKGROUND>タグを使います。

    と表示される。

ファイル名の指定の仕方

背景画像やMIDIを読み込む場合などファイル名を指定するタグがたくさんあります。
それにはSRCとFOLDERキーを使いますが、ここでその使い方を説明しておきます。
  1. SRC [省略不可]
    ファイル名を指定します。
    SRCに指定するのはファイル名だけでなくパスが混じっていても いいです。 "..\back.bmp"の様に親ディレクトリも使えます。
  2. FOLDER [省略時の値はいま読んでいるDNMLブックと同じフォルダ]
    そのファイルのある場所を指定します。
    アーカイブファイルの中のファイルを読み込むときにはそのアーカイブを フォルダとしてパス名を付けてください。
    FOLDERキーを省略すると今読み込んでいるDNMLブックのあるフォルダを使います。
    SRCキーで"C:\title.bmp"とフルパスが指定してあるとFOLDERキーを無視します。
例
  1. <BACKGROUND FOLDER ="c:\" SRC="title.bmp" >
    c:\ドライブにあるtitle.bmpがよみこまれます。

  2. <BACKGROUND SRC="lvns3.pak\c0101.lf2" FOLDER ="c:\program files\toheart\">
    To Heartで使用されている画像はlnvs3.pakというファイルにまとめられています。 ですからSRCは\で区切ってファイル名を例のように指定します。
    FOLDERにはそのファイルのあるフォルダを指定します。

    To HeartのインストールされているフォルダはPCによって違うので普通はエイリアス(別名)を使って
    <BACKGROUND SRC="lvns3.pak\c0101.lf2" FOLDER ="LVNS3">

    と指定します。

    FOLDERキーには常に以下の二つのエイリアスが指定できます。
    PLAYER DNML.EXEのあるフォルダ名
    CURRENT 今読み込んでいるDNMLブックのあるフォルダ名
    グラフィックのファイル名などでFOLDERを省略すると このフォルダから読み込みます。

    <INCLUDE SRC="環境設定.dnml" FOLDER="PLAYER">
     と書いておくと、以下のエイリアスが定義されます。インストールしてあるゲームが増えると 増えいきます。

    LVNS1 雫のインストールされているフォルダ名のエイリアス
    LVNS2 痕のインストールされているフォルダ名のエイリアス
    LVNS3 To Heartのインストールされているフォルダ名のエイリアス
    WA White Albumのインストールされているフォルダ名のエイリアス
    ONE ONEのインストールされているフォルダ名のエイリアス

    LVNS1_FOLDER 雫のインストールされているフォルダ名が裏に書かれた入ったカード
    LVNS2_FOLDER 痕のインストールされているフォルダ名が裏に書かれた入ったカード
    LVNS3_FOLDER To Heartのインストールされているフォルダ名が裏に書かれた入ったカード
    WA_FOLDER White Albumのインストールされているフォルダ名が裏に書かれた入ったカード
    ONE_FOLDER ONEのインストールされているフォルダ名が裏に書かれた入ったカード
    LVNS1_INSTALLED 雫のインストールされていると裏が１になるカード
    LVNS2_INSTALLED 痕のインストールされていると裏が１になるカード
    LVNS3_INSTALLED To Heartのインストールされていると裏が１になるカード
    WA_INSTALLED White Albumのインストールされていると裏が１になるカード
    ONE_INSTALLED ONEのインストールされていると裏が１になるカード

ブックの自動実行

　DNML.EXEのファイル名を変えることによって、同じファイル名のブックを 自動実行します。
　例えば、DNML.EXEをMYGAME.EXEにリネームして起動すると、常に同じフォルダに あるMYGAME.DNMLを読み込んで実行します。こうすればユーザーはDNML.EXEの存在を気にせずに すみます。
　オリジナルのゲームを作って配布したいときはこの機能が便利です。
