ＤＮＭＬを新しいゲームへ対応させる方法
必要な物、必要な事
　DNMLを新しいゲームに対応させるのに、まず必要な物は

画像を読み込むためのSusie Plugin

です。これがなきゃなんともなりません。
BMPなどDNMLが読み込める形へのコンバータでもかまいません。

　他にやらなきゃならないことは「seekgame.txt」と「テンプレート.dnml」 を書くことです。次からはこの方法について説明します。

seekgame.txtの書き方
　DNMLで二次創作を遊ぶのに、まず必要なのはファイルのイントールされている フォルダのエイリアス(別名)を定義することです。
　例えば「ONE～輝く季節へ～」というゲームのグラフィックを使う場合。

　　<ACT SRC="dat00\one0358.bmp" FOLDER="ONE">

と書けば表示されます。"dat00\one0358.bmp"の置いてある場所は パソコンによって違います。しかし、なぜそれでも正しく表示されるのか というと「環境設定.dnml」の中で

　　<ALIAS SRC="ONE" DEST="G:\TACTICS\ONE\">
　　　(DESTの部分はONEのインストールされているフォルダ)

とエイリアスの設定がしてあるからです。こうして"ONE"の部分に正しい フォルダが設定されます。
　このエイリアスの設定に必要なのが「seekgame.txt」です。

「ONE～輝く季節へ～」用の
seekgame.txtの内容
#　'#'で始まる行はコメントで無視されます
#書き方は
#一行目:ゲームの名前
#二行目:エイリアスの名前
#三行目:探すファイル
#です
ONE～輝く季節へ～
ONE
DAT00
'#'で始まる行はコメント行ですので無視されます。よって内容は

ONE～輝く季節へ～
ONE
DAT00

の三行です。 一行目は「ゲームの名前」、二行目は「エイリアスの名前」、 三行目は「探すファイルの名前」です。
「ゲームの名前」は適当につけて下さい。
「エイリアスの名前」はグラフィックを読み込むときにFOLDERに指定する値ですから、 短くてわかりやすい名前を考えて下さい。
「探すファイルの名前」は探すファイルの名前です。ここで指定した ファイルのあるフォルダがエイリアスに設定されます
ONEではグラフィックは全て"DAT00"というファイルに入っています。

　これと同じように対応させたいゲーム用に"seekgame.txt"を書いてください。

テンプレートの書き方
　「テンプレート.dnml」とはウィンドウや文字の表示される位置を あらかじめ指定しておくためのファイルです。 書き方はDNMLブックと同じくタグを使って指定していきます。
STAGEタグ
　まず、最初に画面の大きさを決める<STAGE>タグをかきます。 これは、
<STAGE WIDTH="640" HEIGHT="480">
 と書いておけばよいでしょう。
FONTタグ
　<FONT FACE="ＭＳ ゴシック" HEIGHT="23" SKIP="28"> の用に、FACEにはフォントの名前、HEIGHTには字の高さ、SKIPには 行間の幅を指定します。単位は[画素]です。
SCREENタグ
　次に書くのが文字を表示する範囲を指定する<SCREEN>タグです。 TOP(上端の位置)、LEFT(左端の位置)、WIDTH(幅)、HEIGHT(高さ)の四つの 属性を持ちます。 文字が表示される範囲全体を囲むようにして下さい。

<SCREEN TOP="348" LEFT="47" WIDTH="543" HEIGHT="120">と 指定した例

図の用に画面に表示される文字全体が入るように指定して下さい。
WINDOWタグ
　文字を表示するときにウィンドウを表示するタイプのゲームはこのタグを使います。
　SRCとFOLDER属性にWINDOWに使う画像ファイル名、TOPとLEFTに表示する位置を 指定します。 　画面全体を暗くするゲームでは書く必要はありません。
ICONタグ
　マウスのクリックを待つときのアイコンを指定します。
ここを参考に書いて下さい。
BGMや 背景のエイリアス
　これは必要在りませんが、なるべく書いて下さい。
DNMLでは背景画像やBGMをファイル名やCDのトラックナンバーではなく、 名前で管理しています。
　画像を読み込み用のSusie PluginをSusieと同じフォルダにコピーしてください。
これでそのゲームで使用している画像一覧が見えますので、適当な名前のエイリアス をつけて下さい。
　例えば「ONE～輝く季節へ～」ではBGMの二曲目に

<ALIAS SRC="オンユアマーク" DEST="02.CDA">

とエイリアスがつけてありますから、「オンユアマーク」という曲が 何曲目か知らなくても使うことができます。

インストール法
　最後に自分で作ったテンプレートのインストールの方法を説明します。
　最初に「seekgame.txt」と「テンプレート.dnml」を(他にファイルがあればそれも) そのゲームの名前のフォルダに入れます。そのフォルダをDNML.EXEが インストールしてあるフォルダにコピーして下さい。
　次にスタートメニューより「ゲームの再検索」を選んで下さい。
これで「環境設定.dnml」が更新され、「seekgame.txt」で指定した エイリアスが使えるようになります。
