背景画像や効果音を使うタグです。

BACKGROUND(背景画像の表示)
BGM(BGMの演奏)
SOUND(効果音を使う)

BACKGROUNDタグ

背景画像を表示する。
キー
  1. SRC [COLORキーを使うときはいらない]
    背景に表示するファイル名
  2. FOLDER [COLORキーを使うときはいらない]
    ファイルのあるフォルダ名を指定。
  3. TOP [省略時の値は"0"]
    表示するグラフィックの上端の座標を指定。
  4. LEFT [省略時の値は"0"]
    表示するグラフィックの左端の座標を指定。
  5. WIDTH [省略時の値はグラフィックの幅]
    表示するグラフィックの幅を指定。 "100"の様に直接画像の幅を指定する事と
    (この場合、画像の幅は100[画素]となる)
    "200%"の様に割合でも指定できる。
    (この場合、画像の幅は元の大きさの2倍)
  6. HEIGHT [省略時の値はグラフィックの高さ]
    表示するグラフィックの高さを指定。
    指定の仕方はWIDTHと同じ。
  7. COLOR [SRCをキーを使うときはいらない]
    背景を指定した色で指定。
  8. TRANSPARENT [省略時の値はNONE]
    画像の透明色を指定する。
    　　NONE
    　　　　透明色なし
    　　AUTO
    　　　　画像の一番左上の点の色を透明明色にする。
    　　"#ffffff"の様にHTML式で色を指定
    　　　　その色を透明色にする。

    標準ではBMP画像が読み込めます。それ以外の形式の画像を読み込みたい場合は PLUNINタグを使用してください。

例
  1. <BACKGROUND SRC="back.bmp">
    今読み込んでいるDNMLブックと同じフォルダにあるback.bmpを 背景画像に指定。
  2. <BACKGROUND COLOR="#FFFFFF">
    画面を白くする。カラーの指定の仕方はHTMLと同じ。
  3. <BACKGROUND SRC="階段" FOLDER ="AN" TOP="90">
    LEFT,TOPキーで表示する場所を指定 アトラク＝ナクアのように背景を画面中央に表示する ゲームはこのキーを使用する。

BGMタグ

　BGMを鳴らす。BGMにはCD、MIDIが標準で使用できます。
Direct Show がインストールされているればMP3やAVIなどActive Movieが 再生できる形式が全て再生できます。
キー
  1. SRC [省略するとBGMを止める]
    CD音源を鳴らす場合は 2桁のトラック番号 + 拡張子".CDA" で指定します。
    MIDIやMP3を使用する場合はそのファイル名。
  2. FOLDER [省略時の値は"CURRENT"]
    MIDIを使用する場合はそのファイルのある フォルダ名。
  3. LOOP [省略時の値は無限大]
    BGMを繰り返す回数を指定する。
  4. TIME [省略時の値は0]
    BGMをフェードアウトさせる。
    BGMの音量が0になるまでの時間を指定します。
    </BGM>でBGMを止めるときのみ使えます。
    単位は[ms](1000[ms]=1秒)
  5. MODE [省略時の値は"WAIT"]
    "WAIT"か"PASS"をしていする。
    </BGM>でBGMを止めるときのみ使える。
    "WAIT"だとBGMがフェードアウトするときに音量が0になるまで
    ゲームを止める。 "PASS"だとBGMがフェードアウトしながらゲームを進める。
例
  1. <BGM SRC="03.CDA">
    CDのトラック3を演奏する。
  2. <BGM SRC="bgm1.mid">
    FOLDERキーがないので、今読み込んでいるDNMLブックと同じフォルダに有る bgm1.midを演奏します。
  3. </BGM>
    BGMの演奏を停止。
  4. </BGM TIME="5000">
    5秒間かけてBGMをフェードアウト
    そのあいだゲームは止まります。
  5. </BGM TIME="10000" MODE="PASS">
    5秒間かけてBGMをフェードアウト
    BGMをフェードアウトさせつつ、ゲームを進めます。

SOUNDタグ

効果音を鳴らす。
WAVE形式とP16形式(Leafのゲームで使われている)が使えます。
DirectSound対応のサウンドカードでなければ、LOOP属性と</SOUND>は 使えません。
キー
  1. SRC [省略不可]
    鳴らすファイル名を指定。
  2. FOLDER [省略時の値は"CURRENT"]
    鳴らすファイルのあるフォルダを指定。
  3. MODE [省略時の値は"WAIT"]
    MODE="WAIT"で効果音が鳴り終わるまで、次に表示する絵や文字を 出しません。
    MODE="PASS"で効果音が鳴り終わるのを待たずにゲームを進めます
  4. LOOP [省略時の値は"1"]
    効果音を繰り返す回数を指定します。
    "0"を指定すると</SOUND>で止めるまで鳴り続けます。
    この時のMODEは強制的に"PASS"になります。
  5. </SOUND>
    現在鳴っている全ての効果音を中止します。

例
  1. <SOUND SRC="パン" FOLDER="LVNS3">
    To Heartのテンプレートで"パン"は"LVNS3DAT.PAK\TH_VD01.P16" に別名を指定してあります。 これでTo Hreatで使われている"パン"と聞こえる効果音を鳴らします。

  2. <SOUND SRC="pi.wav" MODE="PASS">
    今読んでいるDNMLブックと同じフォルダにある"pi.wav"を ならします。MODEはPASSですので鳴り終わるのを待たずに ゲームを進めます。

  3. <INCLUDE SRC="痕\テンプレート.dnml" FOLDER="PLAYER">
    <SOUND SRC="リーン" FOLDER="LVNS2" LOOP="0">
    ・
    ・
    ・
    </SOUND>

    LOOP="0"なので</SOUND>がくるまで鈴虫の鳴き声が鳴り続けます。
