主人公の名前などを読者に入力してもらいます。
HTML風のボタンやエディットボックスを表示します。

FORM(入力の開始)
INPUT(ボタンなどの表示)

FORM

HTMLのFORMタグと同等の機能を提供する。
カードの内容を読者が入力できる
これで読者が主人公の名前つけたりできる。
<FORM>と</FORM>で囲まれた部分にINPUTタグを置いて
ボタンやエディットボックスを配置できます。

例

  1. </FORM> [絶対に省略不可]
    FORMタグを使ったら必ず</FORM>で閉じてください。

INPUT

HTMLのINPUTと似た機能を提供する。
ALIASやANSWERの内容を読者が入力できる。
読者に主人公の名前を付けさせたい時などに使ってください。
使い方はHTMLと同じです。

必ず一つ以上のSUBMIT(決定ボタン)を使ってください。

例

  1. TYPE [省略時の値はTEXT]
    フォームの種類を指定
    "TEXT"(文字を入力),
    "CHECKBOX"(ON,OFFを指定できるボタン)
    "RADIO"(一つだけ選択できるボタン)
    "SUBMIT"(入力を終わる)
    "RESET"(入力した内容をリセット)
    が使用できる。
  2. NAME [SUBMIT,RESET以外は省略不可]
    入力結果を受け取るカードの名前を指定する。
  3. VALUE [省略時の値はなし]
    TEXTの場合は
    最初から表示される文字。
    VALUEが省略され、NAMEで指定されたカードが既に存在した場合には
    カードの内容が表示される。

    RADIO,CHECKBOXの場合は
    それがONになった時、カードに入る文字。

    SUBMIT,RESETの場合は
    ボタンに表示される文字。
    SUBMITが押されたときNAMEキーがある場合はそのカードにもこの値が入る。
    複数のSUBMITをおいた場合には、この値を調べればどのボタンが押されたか わかる。

  4. TOP [省略時はDNMLが適当に決める]
    フォームの上からの位置を指定する
    単位は画面上からの画素数
  5. LEFT [省略時はDNMLが適当に決める]
    フォームの左からの位置を指定する
    単位は画面上からの画素数
  6. WIDTH [省略時はDNMLが適当に決める]
    フォームの幅を直接指定
    単位は画素
  7. HEIGHT [省略時はDNMLが適当に決める]
    フォームの高さを直接指定

    1. <FORM>
      名字
      <INPUT TYPE="TEXT" NAME="名字" VALUE="越前"><NL>
      名前
      <INPUT TYPE="TEXT" NAME="名前" VALUE="康介"><NL>
      どの扉を開ける？><NL>
      <INPUT TYPE="RADIO" NAME="色" VALUE="赤">赤
      <INPUT TYPE="RADIO" NAME="色" VALUE="青">青
      <INPUT TYPE="RADIO" NAME="色" VALUE="緑">緑<NL>
      <INPUT TYPE="CHECKBOX" NAME="コードネーム" VALUE="付ける">コードネームを付ける<NL>
      <INPUT TYPE="SUBMIT" VALUE="決定"><NL>
      <INPUT TYPE="RESET" VALUE="リセット"><NL>
      </FORM>

      と書くと以下のように表示される。
      名字　　
      名前　　
      どの扉を開ける？
      赤 青 緑
      コードネームを付ける


      INPUTタグではますTYPEキーで、フォームの種類を指定します。
      TYPE="TEXT"で文字を入力できます。
      NAMEには入力された文字をかくカードの名前を指定します。
      ここではNAME="名字"となっているので<<名字>>と書くと、読者の 入力した名字が表示されます。
      VALUEには最初から表示される文字を書きます。

      TYPE="RADIO"でラジオボタンが使えます。
      これは同じNAMEのボタンのうち、どれか一つだけが選択されます。
      NAMEで指定されたカードには最後に選ばれていたラジオボタンのVALUEが 入ります。

      TYPE="CHECKBOX"でON,OFFの状態を選択できるボタンを表示します。
      ONであればNAMEで指定したカードにVALUEで指定した文字が入ります。

      TYPE="RESET"でリセットボタンを表示します。
      VALUEにはボタンに表示される文字を指定します。
      このボタンを押すと、入力された値を全て初期値に戻します。

      TYPE="SUBMIT"で決定ボタンを表示します。
      VALUEにはボタンに表示される文字を指定します。
      このボタンは必ず一つ以上は位置してください。
      そうしないと、次に進めなくなります。

    2. 入力の使い方
      そいつの名前は<<名字>><<名前>><NL>
      せっかくだからこの<<色>>の扉を開くぜ<NL>
      <EVENT ANSWER="(コードネーム?[付ける])">
      コードネームはコンバット<<名字>><NL>
      </EVENT>

      以上のように書くと
      そいつの名前は越前康介
      せっかくだからこの赤の扉を開くぜ
      コードネームはコンバット越前
       と表示される。
      それぞれ名前や色などは読者の選択したものが表示されます。
