初期設定です。
二次創作の作品を作るときはここを見る必要は必要はありません。
オリジナル作品を作るときでも、絶対必要なタグはSTAGEのみです。
他は全て省略できます。
STAGE以外は物語の途中でも変更できます。

STAGE(画面の大きさ)
SCREEN(文字の表示される範囲)
SPACE(人物の表示される範囲)
WINDOW(文字を表示するウィンドウの画像を指定する)
PLUGIN(画像読み込み用Susie Pluinを設定)
ICON(クリック待ちのアイコンを指定する)
CURSOR(マウスカーソルを指定する)

STAGEタグ

画面の大きさを設定する。
キー
  1. WIDTH [省略不可]
    画面の横幅を指定。
  2. HEIGTH [省略不可]
    画面の高さを指定。
例
  1. <STAGE WIDTHE="640" WIDTH="480">
    画面の大きさを幅640x縦480に設定。

SCREENタグ

文字を表示する範囲の大きさを設定
キー
  1. TOP [省略不可]
    文字を表示する範囲の上端の座標を指定。
  2. LEFT [省略不可]
    文字を表示する範囲の左端の座標を指定。
  3. WIDTH [省略不可]
    文字を表示する範囲の横幅を指定。
  4. HEIGHT [省略不可]
    文字を表示する範囲の高さを指定。
  5. SHUT [省略時はAUTO]
    文字を消す時の条件を指定する。
    AUTO人物や背景が変更されるときに文字を消す
    NONE常に表示
例
  1. <SCREEN TOP="20" LEFT="20" WIDTH="600" HEIGHT="440">

SPACEタグ

人物を表示する範囲を指定します。
「PIA☆キャロットへようこそ！２」や「同級生」の様に
人物を画面の上の方に表示するゲームではこのタグを使用します。
標準ではSTAGEと同じ大きさになっています。
キー
  1. TOP [省略時の値は0]
    人物を表示する範囲の上端の座標を指定。
  2. LEFT [省略時の値は0]
    人物を表示する範囲の左端の座標を指定。
  3. WIDTH [省略不可]
    人物を表示する範囲の横幅を指定。
  4. HEIGHT [省略不可]
    人物を表示する範囲の高さを指定。
例
  1. <SPACE TOP="0" LEFT="0" WIDTH="640" HEIGHT="300">
    人物の画像は上300[画素]の部分にのみ表示される。

WINDOWタグ

テキストを表示するためのウィンドウのグラフィックを指定する。
ONEやWhite Albumなどウィンドウを表示するゲームにはこのタグを使って 指定する。
このタグを省略すると、文字を表示する時に画面全体の輝度を落とします。
キー
  1. SRC [省略不可]
    グラフィックのファイル名を指定。
  2. FOLDER [省略時の値は"CURRENT"]
    ファイルのあるフォルダを指定。
  3. TOP [省略不可]
    ウィンドウの表示位置を指定。次に表示する文字の上端の座標を 指定。
  4. LEFT [省略不可]
    ウィンドウの表示位置を指定。次に表示する文字の上端の座標を 指定。
  5. WIDTH [省略時の値はグラフィックの幅]
    表示するグラフィックの幅を指定。 "100"の様に直接画像の幅を指定する事と
    (この場合、画像の幅は100[画素]となる)
    "200%"の様に割合でも指定できる。
    (この場合、画像の幅は元の大きさの2倍)
  6. HEIGHT [省略時の値はグラフィックの高さ]
    表示するグラフィックの高さを指定。
    指定の仕方はWIDTHと同じ。
  7. EFFECT [省略時の値は"EF_FADEIN"]
    ウィンドウを表示するときに効果を指定します。
    詳しくはEFFECTキーを参照して下さい。
  8. ALPHA [省略時は100]
    ウィンドウの不透明度を指定する。
    数字で指定すると
    画像全体の不透明度となる。
    値は0から100で
    0で完全に透明。
    100で透過せずに表示。

    ファイル名で指定すると
    その画像がアルファチャンネルとなる。
    (ALPHAで指定した画像はモノクロに変換され、
    それがウィンドウの
    不透明度(いわゆるアルファチャンネル)となります。
    ALPHAで指定した画像の黒い部分は透明になります。
    白い部分は不透明で普通に表示されます。
    灰色の部分は半透明で表示されます。
    この画像のFOLDER属性はSRCと共有しますので
    Windowの画像ファイルと同じフォルダに置いて下さい。
    形式はDNMLで読める形なら何でもかまいません)

  9. SUBFOLDER [省略時の値はFOLDERと同じ]
    ALPHAで指定したファイルのあるフォルダを指定。

  10. /WINDOW
    Windowを使用しない。
  11. 全てのキーを省略
    文字を表示するときには、画面全体を暗くする(初期値はこれ)
  12. SHUT [省略時はAUTO]
    ウィンドウを閉じる時の条件を指定する。
    AUTO人物や背景が変更されるときに閉じる
    NONE常に表示
  13. TRANSPARENT [省略時の値はAUTO]
    画像の透明色を指定する。
    　　NONE
    　　　　透明色なし
    　　AUTO
    　　　　画像の一番左上の点とRGBで(255,0,255)の色を透明色にする。
    　　"#ffffff"の様にHTML式で色を指定
    　　　　その色を透明色にする。


例
  1. <WINDOW SRC="ONE\window.bmp" FOLDER="PLAYER" LEFT="30" TOP="400" ALPHA="50">
    文字を表示するウィンドウは"one\window.bmp"とする。
    表示位置は画像の左端の座標は30,上端の座標は400とする。
    不透明度50の半透明で表示する。
  2. </WINDOW>
    　Windowを使用しない。
  3. <WINDOW>
    　文字を表示するときは画面全体を暗くする。

PLUGINタグ

グラフィックの読み込みに使用するSusie-Pluginを 指定する。標準でBMP,JPEG,PNG形式の画像が読み込めます。

　ファイル名がAXではじまるアーカイブ展開用プラグインはDNML.EXEと同じフォルダにおけば自動的に使用します。 　しかし、同じ拡張子用のプラグインが複数有る場合は、指定しておいて下さい。

(JPEG,PNGはSusie-Pluginを通して読み込みます。ゲームを配布する時に DNML.EXEを一緒に配布する場合は、IFJPEGD.SPIとIFPNG.SPIとIFPNG.TXTも一緒に 配布して下さい。この二つのSusie-PluginはPLUGINタグを使わなくても、 自動的に使用します。 IFPNG.SPIはgv9k-setg さんの作品です。)

キー
  1. SRC [省略不可]
    関連づけする拡張子を指定。
  2. NAME [省略不可]
    PLUGINの名前を指定。Susie PluginはDNML.EXEを同じ フォルダにおいてください。
    例
  1. <PLUGIN SRC="LF2" NAME="IFLF2.SPI">
    拡張子LF2のファイルはIFLF2.SPIを使用して読み込む。

  2. White Album用テンプレート
    <PLUGIN SRC="PAK" NAME="AXLFPAK2">
    <PLUGIN SRC="GRP" NAME="IFLFGRP.SPI">

    こみっくパーティー用用テンプレート
    <PLUGIN SRC="PAK" NAME="AXCP.SPI">
    <PLUGIN SRC="GRP" NAME="IFCP.SPI">

    PAKを展開するプラグインが複数有るので、指定しておく。

ICONタグ

マウスを入力待つ時のアイコンを設定する。
キー
  1. SRC [省略不可]
    グラフィックのファイル名を指定。
  2. FOLDER [省略時は"CURRENT"]
    ファイルのあるフォルダを指定。
  3. MODE [アイコンを登録するときは省略不可]
    アイコンを表示する場合を指定。
    BRとPがある。BRは改行を待つ時。 Pは改ページを待つ時に指定のアイコンを表示する。
  4. LEFT [省略した場合は最後に表示した文字の横]
    アイコンを表示する位置。
  5. TOP [省略した場合は最後に表示した文字の横]
    アイコンを表示する位置の縦。
  6. TIME [省略時は無限大]
    アイコンを表示する時間。単位は[ms]。
    省略すると左クリックがあるまで、同じアイコンを表示しつづけます。 アイコンをアニメーションさせる場合はICONタグをならべて
    書いて下さい。MODEが同じICONを順番に表示して、最後まで行ったら また最初に定義したICONタグに戻って表示します。
    登録できるアイコンの数に制限はありません。

  7. </ICON>
    以前にICONタグで指定したアイコンの使用を中止する。
    　</ICON>の様にMODEを指定しないで使うと <ICON>を使うまでアイコンの使用を一時中止します。

    　</ICON MODE="P">の様にMODEを指定して使うと、そのタグを 使ったときに表示するように設定したアイコンを全て削除します。
    <ICON>を使っても元に戻りません。全く新しいアイコンを登録し直し たい時にはこちらを使って下さい。

例
  1. < ICON SRC="ToHeart\newline.bmp" FOLDER="PLAYER" MODE="BR" TIME="1000">
    < ICON SRC="ToHeart\blank.bmp" FOLDER="PLAYER" MODE="BR" TIME="1000">

    改行の左クリックを待っている時にnewline.bmpとblank.bmpを1秒ごとに 切り替えて表示する。
  2. 例１のつづきです。
    <BR>
    <-- ここではアイコンが表示されています。-->
    <BACKGROUND SRC="イベントCD">
    </ICON><-- アイコンの使用を一時中止-->
    <BR>
    <-- イベントCGを表示している間はアイコンを表示しません -->
    <ICON><-- アイコンの使用を再開-->
    <BR>
    <-- ここではアイコンが表示されています。-->

  3. 例２のつづきです。
    <BR>
    <-- ここではアイコンが表示されています。-->
    </ICON MODE="BR"><-- アイコンの使用を停止-->
    <BR>
    <-- アイコンは表示されていません -->
    < ICON SRC="ToHeart\newline2.bmp" FOLDER="PLAYER" MODE="BR" TIME="1000">
    < ICON SRC="ToHeart\blank2.bmp" FOLDER="PLAYER" MODE="BR" TIME="1000">
    <BR>
    <-- ここではさっきとは違うアイコンが表示されています-->

CURSORタグ

マウスカーソルを指定する。
キー
  1. SRC [省略不可]
    カーソルのファイル名を指定。
  2. FOLDER [省略時は"CURRENT"]
    ファイルのあるフォルダを指定。
例
  1. < CURSOR SRC="one\one.cur" FOLDER="PLAYER">

    マウスカーソルをone.curに設定。
