そのほかのタグです。

COMMAND(Windowsコマンドの実行)
BOOKMARK(しおりの作成)
TITLE(作品タイトルの記入)
COVER(作者などの記入)
END(ブックの終了)
SNAP(画像の保存)
TRAP(スキップの停止)
!(コメント行)
#(コメント範囲)

COMMANDタグ

外部プログラムを実行します。
実行ファイル以外が指定された場合は、その拡張子に関連づけられた プログラムで開きます。
"http://"で始まる文字が指定されたときは、そのURLを開きます。
このタグはDNMLブラウザの[外部プログラムの起動を許可]のチェックボックスを OFFにする事で無効になります。
  1. SRC [省略不可]
    実行するコマンド。
  2. FOLDER [省略時の値は"CURRENT"]
    コマンドを実行するときのカレントフォルダを指定。
例
  1. <COMMAND SRC="notepad.exe readme.txt">
    いま読み込んでいるDNMLブックと同じフォルダにあるreadme.txtを メモ帳で開く

  2. <COMMAND SRC="readme.html">
    いま読み込んでいるDNMLブックと同じフォルダにあるreadme.htmlを 拡張子htmlに関連づけられたプログラムで開きます。

  3. <COMMAND SRC="http://member.nifty.ne.jp/karin/" >
    "http://member.nifty.ne.jp/karin/"をWWWブラウザで開きます。

BOOKMARKタグ

しおり(セーブ)を作成をする。

「かまいたちの夜」や「街」のようなオートセーブを使いたい時などに 使って下さい。

それ以外の時はこのタグを使わなくてもDNMLブラウザが 自動的にしおりを作成します。

キー
  1. キーを指定しない
    キーを指定せずに<BOOKMARK>とタグだけを書いた場合は 現在のしおりに強制セーブします。
    セーブされるのは以前に<P>タグを使った時です。

  2. MODE [省略時の値はMANUAL]
    しおりのタイプを指定します。

    AUTOを指定すると<P>タグがある度に強制セーブします。さらにユーザーはセーブ出来なくなります。
    (「かまいたちの夜」「街」などチュンソフト式)

    SEMIAUTOを指定するとユーザーはセーブ出来なくなります。
    改頁時にもサーブされませんので、DNML作者が<BOOKMARK>タグ を使ってセーブしてやる必要があります。
    章の始めやエンディングのみセーブできるようにしたいなど、しおりを DNML作者が管理したいときに使います。

    MANUALを指定すると、<BOOKMARK>タグをつかって強制セーブするか ユーザーがセーブを選択したときにセーブされます。
    ユーザーは自由にセーブ出来ます。(「痕」「To Heart」などLeaf式)

    TOPPAGE 以上三つのMODEキーの値はしおりの動作を指定する物でしたが、 これは違う物です。
    MODEキーにTOPPAGEを指定すると最初のページにしおりを戻してセーブします。
    見たエンディングによってシナリオの変化するゲームには最後に これを使ってください。

  3. ALT [省略時の値は前回の値]
    セーブデータへのコメントを指定。 しおりを選択するウィンドウで
    [しおり１ プロローグ]
    [しおり２ 第一章]
    の様にしおりのコメントをつけたい時に使います。

    例


    1. <BOOKMARK ALT="プロローグ">
      ・
      ・プロローグの内容
      ・
      <BOOKMARK ALT="第一章">
      ・
      ・第一章の内容
      ・

      プロローブの部分でセーブするとしおりの選択画面で
      [しおり１ プロローグ]
      と表示される。

TITLEタグ

ウィンドウのタイトルに指定された文字を表示します。
  1. ALT [省略不可]
    ウィンドウのタイトルに指定された文字を表示。
例
  1. <TITLE ALT="柏木家の食卓2">

COVERタグ

　このタグは、物語には一切影響しません。
　作品を整理する時などに重要なので、ブックの最初の方になるべく書いて下さい。
  1. AUTHOR [省略可能]
    作者の名前を書く。
  2. TITLE [省略可能]
    作品のタイトルを書く。
  3. MAIL [省略可能]
    e-mailアドレスを書く。
  4. HOMEPAGE [省略可能]
    ホームページのアドレスを書く。
  5. DATE [省略可能]
    書いた日付を書く。"年/月/日"の順番で書きます。
  6. COMMENT [省略可能]
    コメントを書く。
  7. GENRE [省略可能]
    作品のジャンルを書く。二次創作の場合は、 ここにACTタグのFOLDERキーなどで使うALIASの名前を書いてください。 (例えはToHeartは"LVNS3"、ONE～輝く季節へ～は"ONE"、Kanonは"KANON"となります)
例
  1. <COVER
    TITLE = "Kanonサンプル"
    AUTHOR = "花梨"
    MAIL = "karin@paw.office.ne.jp"
    HP = "http://www.vector.co.jp/authors/VA015183/"
    DATE = "1999/6/13"
    GENRE = "KANON"
    COMMENT = "DNMLのサンプルファイルです。すべてのDNMLにはなるべくこの形式でヘッダを付けてください"
    >

ENDタグ

DNMLの実行を終了します。
このタグがあると、まだ続きが書いてあっても中止します。
キー
  1. ALT [省略時の値は"おしまい"]
    終了時に出でるウィンドウのメッセージを指定する。
  2. MODE [省略時の値はなにもしない]
    TOPを指定すると、しおりを一番最初のページまで戻します。
例
  1. <A NAME="エンド１">
    ・
    ・
    <END ALT="ありがとうございました。感想など有りましたらkarin@shiho-fan.club.or.jpまで">
    <A NAME="エンド２">
    ・

    以上のDNMLを実行するとタグのある位置で終了し、 以下のDNMLは実行しません。 終了したあと、左クリックすると「ありがとうご・・・・」の メッセージを表示します。

SNAPタグ

画面をセーブします。
画像のサムネイルなどを作成したいときに使います。
キー
  1. WIDTH [省略時の値はグラフィックの幅]
    高さが指定してあるときには縦横の比が同じになるようにする]
    画像の幅を指定。
  2. HEIGHT [省略時の値はグラフィックの高さ
    幅が指定してあるときには縦横の比が同じになるようにする]
    画像の幅を指定。
  3. NAME [省略時の値は画面全体]
    セーブする人を指定する。
    この属性が指定していないときには画面全体を保存する。
  4. SRC [省略時の値は元のファイル名]
    セーブするファイル名
  5. FOLDER [省略時の値は"CURRENT"]
    セーブするファイルを置くフォルダ。
  6. MODE [省略時の値はBMP]
    セーブするファイルの形式。
    BMPとJPEGが指定できる。
例
  1. <ACT NAME="芹香" SRC="LVNS3DAT.PAK\C0202.LF2" FOLDER="LVNS3">
    <SNAP NAME="芹香" >
    <!-- 現在のフォルダに"C0202.BMP"という名前でセーブ -->
    <SNAP NAME="芹香" MODE="JPEG" >
    <!-- 現在のフォルダに"C0202.JPG"という名前でセーブ -->
    <SNAP NAME="芹香" SRC="芹香.JPG"MODE="JPEG" WIDTH="70">
    <!-- 現在のフォルダに幅が70[画素]、"芹香.JPG"という名前でセーブ -->

TRAPタグ

物語には影響しない。
次の選択肢まで進めるを選択した時、 このタグがあると止まる。
例
  1. <TRAP>

!タグ

一行コメント、改行があるまでコメントとして扱われ実行されない。
例
  1. <! この部分は実行されません。

#タグ

複数行コメント、#>があるまでコメントとして扱われ実行されない。
例
  1. <#
    この部分は実行されません。
    必ず閉じてください。
    #>
