画面に選択肢などを表示して、物語を分岐させます。

A HREF(選択肢の表示)
A NAME(分岐する先の指定)
QUESITION(過去の選択により分岐)
MEMO(前回のプレイ結果などによる分岐)
EVENT(イベントを発生)
カードの組合わせ(複数の選択肢の組み合わせによる分岐)
高度なカードの使い方

A HREFタグ

物語を分岐させるための選択肢を画面に表示させます。
複数の選択肢を表示する場合(普通そうだけど)は <A HREF>タグを続けて書いてください。<A HREF> 以外のタグが出るまで、選択肢をならべて表示します。
キー
  1. HREF [省略時には選択されてもそのまま物語をすすめます]
    この選択肢が選ばれたときのリンク先を指定する。
  2. ALT [省略時にはこの選択肢が自動的に選ばれる]
    選択肢に表示する文字を指定。
  3. ANSWER [省略時にはなにも設定ない]
    QUSTIONタグへの解答を指定。くわしくはQUESIONタグの説明 みてください。

    高度な使い方として、ここでカードの計算をすることができます。
    計算はこの選択肢が選ばれたときのみ実行されます。
    サンプルはカードの高度な使い方を見て下さい。
  4. VIEW [省略時にはこの選択肢は常に表示させる]
    この選択肢を表示する条件を指定します。
    指定のやり方はQUSTIONタグのANSWERと おなじです。
  5. ENABLE [省略時には"選択できる"]
    この選択肢を選択できるする条件を指定します。
    指定のやり方はQUSTIONタグのANSWERと おなじです。
    この中の条件を満たさなかった場合は選択肢は表示はされますが、
    選択できません。
例
  1. <A HREF="二階.dnml" ALT="二階にいく">
    <A HREF="#一階" ALT="一階にいく">
    <A HREF="二章.dnml#外" ALT="外に出る">
    <A HREF="" ALT="帰る">
    <A HREF="ゲーセン" ALT="ゲーセンに行く" VIEW="志保と約束">

    のように書くと
    二階にいく
    一階にいく
    外に出る
    帰る
    ゲーセンに行く
    と画面に選択肢が出る。

    「二階にいく」を選択すると「二階.dnml」の先頭に飛ぶ

    「一階にいく」を選択すると今読んでいるファイル内で、<A NAME>タグで
    "一階"を指定してある場所まで飛ぶ

    「外に出る」を選択すると「二章.DNML」の<A NAME>タグで
    "外"を指定してある場所まで飛ぶ

    「帰る」を選択するとHREFキーがないのでそのまま進める。

    「ゲーセンにいく」は以前にANSWERに「志保と約束」を指定してある 選択肢を選んだことがある時のみ表示されます。


    分岐の仕方はHTMLとほとんど同じです。

  2. 選択肢を表示せずにある点を通過しただけでANSWERを設定したい場合は
    <A HREF="" ANSWER="通過"> とALTを省略してHREFに""を指定してください。

  3. 三つあるアイテムの内、二つを選ばせる例です。
    このサンプルは「DNMLBook\サンプル\viewとenable.dnml」に入っています。

    <A NAME="選択開始">
    <NP>
    　　<QUESTION ANSWER="(アイテムの数=((銃+弾)+鍵))">
    <!--最初にアイテムの数を計算します-->
    　　<QUESTION HREF="#選択終わり" ANSWER="(アイテムの数?2)">
    <!--アイテムを２個持っていたら終わり-->
    　　<EVENT ANSWER="(アイテムの数?0)">
    　　　　「この中から二つだけもって行け」<BR>
    　　</EVENT>
    <!--まだアイテムを持っていなかったらこの台詞が表示される-->

    　　<EVENT ANSWER="(アイテムの数?1)">
    　　　　「もう一つだ」<BR>
    　　</EVENT>
    <!--一つ持っていたらこの台詞が表示される-->
    <EVENT ANSWER="鍵">いまは鍵を持っている<BR></EVENT>
    <EVENT ANSWER="銃">いまは銃を持っている<BR></EVENT>
    <EVENT ANSWER="弾">いまは弾を持っている<BR></EVENT>
    <!--アイテムを持っていたらそれぞれ表示される-->

    <A HREF="#選択開始" ALT="では鍵を持っていく" ANSWER="鍵" ENABLE="(!鍵)">
    <A HREF="#選択開始" ALT="では銃を持っていく" ANSWER="銃" ENABLE="(!銃)">
    <A HREF="#選択開始" ALT="では弾を持っていく" ANSWER="弾" ENABLE="(!弾)">
    <!--持っているアイテムは選択できない-->
    <A NAME="選択終わり">

    行け。<BR>



  4. 例３で鍵、もしくは銃と弾を選択していれば、扉の中に入れます。
    扉がある。<BR>
    <EVENT ANSWER="鍵">鍵を持っている<NL></EVENT>
    <!--鍵を持っていたら表示される-->
    <EVENT ANSWER="(銃&(!弾))">銃だけを持っている<NL></EVENT>
    <!--銃だけをを持っていたら表示される-->
    <EVENT ANSWER="((!銃)&弾)">弾だけを持っている<NL></EVENT>
    <!--弾だけをを持っていたら表示される-->
    <EVENT ANSWER="(銃&弾)">銃と弾を持っている<NL></EVENT>
    <!--銃と弾をを持っていたら表示される-->
    <BR>
    <A HREF="" ALT="他の道を探す">
    <A HREF="扉の中.dnml" ALT="鍵を使う" VIEW="鍵">
    <A HREF="扉の中.dnml" ALT="銃で壊す" VIEW="(銃&弾)">

キー

    リンク先となる名前を指定。

QUESTIONタグ

遅延分岐、A HREFタグで出された解答に応じて分岐する。
以前にANSWERに指定された選択肢を選択したことがあれば
HREFで指定されたところに飛ぶ。
キー
  1. HREF [省略時には選択されてもそのまま物語をすすめます]
    キーワードが一致したときの、リンク先を指定します。
  1. ANSWER [省略不可]
    分岐の条件となるカードの名前を指定。
    カードを組み合わせて使う事が出来ます。
例
  1. どの本を買おうか
    <A HREF="" ALT="Ａ.ギャグ漫画" ANSWER="漫画を買った">
    <A HREF="" ALT="Ｂ.Hな本" >
    ・
    ・
    ・
    ・
    どんな本を買ったの？
    <QUESTION ANSWER="漫画を買った" HREF="初音と読む.dnml">
    初音さんに見つからないように隠さないと。


    以上のDNMLを実行するとまず画面に

    －－－－－－－－－－－－－－－－－－－
    どの本を買おうか
    Ａ.ギャグ漫画
    Ｂ.Hな本
    －－－－－－－－－－－－－－－－－－－

    の選択肢がでます。
    どちらを選んでもHREFキーが省略してあるため、分岐はしません
    (もちろん分岐させてもOKです。)
    [Ａ.ギャグ漫画]を選択するとANSWERキーに"漫画を買った" が指定されているため、「漫画を買った」と書かれたカード が読者に配られます。
    　そのままシナリオが進み、「どんな本をかったの？」 と画面に表示された後にQUESTIONタグが実行されます。
    　読者がANSWERキーで指定した名前のカードを持っていれば、 HREFで指定された場所へ飛びます。なければそのまま シナリオはすすみます。

EVENTタグ

条件がそろったときに<EVENT>と</EVENT> の間にあるタグを実行する。
キー
  1. ANSWER [省略不可]
    イベントの条件となるカードの名前を指定。
    カードを組み合わせて使う事が出来ます。
例
  1. <A HREF="" ALT="鍵を拾う" ANSWER="鍵持ってる">
    <A HREF="" ALT="拾わない">
    　　　・
    　　　・
    　　　・
    扉がある。どうする？
    <EVENT ASNWER="鍵持ってる">
    　　　　<A HREF="扉の中.dnml" >
    </EVENT>

最初の選択肢で"鍵を拾う"を選択した場合のみに、"扉の中.dnml"を実行する。

MEMO

　カードの内容をメモに書いたり読んだりします。
　このメモはセーブやロードしても消えません。
これでクリア後に選択肢が増えるシナリオや 全てのセーブデータで合計したCG達成率などができます。
　読み書きできるメモ用紙は2枚有ります。
そのしおり専用の１枚(クリアしたエンディングの数など)と、しおり全体で共有される1枚(CG達成率など)の

キー

  1. SRC [省略不可]
    書き写す"元"の名前を指定します。
  2. DEST [省略不可]
    書き写す"先"の名前を指定します。

    　 SRCとDESTにはカードの名前か メモ用紙の名前("BOOKMARK"か"BOOK")が指定できます。

    　SRCにカードの名前を指定した場合にはDESTに指定したメモ用紙に 内容が書き写されます。
    　DESTにカードの名前を指定した場合にはメモ用紙に以前メモした内容 がカードに書き込まれます。

    　 "BOOKMARK"を指定した時にはそのメモはそのしおり
    からしか見えません。そのしおりでクリアしたエンディングの数など、 他のしおりと関係ないメモにはこれを使って下さい。
    　 "BOOK"を指定したときにはメモの内容がすべてのブックマークで共有されます。
    全キャラクリアしたらタイトル画面におまけモードを足したいとか、
    CG達成率などを使いたいときにはこちらを指定して下さい。

    　SRCのみに使用できる特殊な名前として"CLEAR"が有ります。 これを使用するとDESTに指定されたメモ用紙の内容が全て消えます。

例
    くわしいサンプルは「DNMLBook\サンプル\memo.dnml」を見て下さい。
  1. <MEMO SRC="CLEAR" MODE="BOOKMARK">

    BOOKMARKにメモされた内容を全て削除します。
  2. <MEMO SRC="CLEAR" MODE="BOOK">

    BOOKにメモされた内容を全て削除します。

ANSWERキー内での、カードの組み合わせ

　ANSWER="漫画を買った"などのように直接カードの名前を指定しただけでは、 使いにくいこともあると思います。
　例えば二つのイベントを同時にクリアしたのみに物語を分岐させたいこと もあるでしょう。
　ポーカーでは同じ数字の札を持つことで「ツーペア」という役を作るように、 DNMLでも読者が持っているカードの組み合わせを見て分岐できます。
　ここではその方法について説明します。
　多くのアドベンチャーゲームで「フラグ」と呼ばれる物語の 分岐管理を、DNMLではトランプゲームの比喩で表現します。
　読者は作者の用意する選択肢の中から好きなカードを選択し、 作者は読者が持っているカードから、どのような役ができるか見ているわけです。


　以下のような選択肢を選んだ場合。

<A HREF="" ALT="Ａ.弾をもらう" ANSWER="弾を持っている">

　読者には「弾を持っている」と書かれたカードが配られます。 選択により渡されたカードの裏には1と書いてあります。つまり、これはトランプカードような物で表には「弾を持っている」 、裏には「1」と数字が書いてあります。
　次にこの様な選択肢を選んだ場合。

<A HREF="" ALT="銃をもらう" ANSWER="銃を持っている">

　読者には「銃を持っている」と書かれたカードが配られます。
　そこで以下のQUESTIONタグが実行されたとします。

<QUESTION ANSWER="(銃を持っている & 弾を持っている)"
　　　HREF="敵を倒した.dnml" >

　QUESTIONタグが実行されると、ゲームの親はいったん読者より全てのカードを預かります。

　預かったカードよりANSWERキーの「(銃を持っている & 弾を持っている)」の括弧の中に書かれた 名前のカードを探します。同じ名前のカードがあればそのまま使い、なければ裏に0と書かれたカードを用意します。
　次にその裏の数字を見て、カードの名前を数字に置き換えます。
　この結果二つとも選択肢を選んだことがあれば、「(銃を持っている & 弾を持っている)」は「( 1 & 1 )」となります。
　次に下に書いてある、「使える組み合わせリスト」の6番をを見てください。
　「&」は「両方とも0でない時に括弧の値は1になる。それ以外は0」と書いてあります。
　「( 1 & 1 )」は両方とも0でありませんので1となります。
　最終的に得られた値は0以外ならHREFのリンク先へ飛びます。
　もし、両方の選択肢を選んだことがなければ、最終的な値は0になるので そのまま話を進めます。

　最後にこちらで用意したカードを含めて、全てのカードを読者に返します。

　カードの裏の値は読者が持っていれば裏に書かれた値、なければ0になる。
　ANSWERキーの中で()を使った場合、最後に計算された括弧の値が0でなかったら HREFのリンク先にジャンプする。
　()を使わなかった場合は指定された名前のカードをもっていればHREFを実行する。 (そのカードの裏の値は0の時はのぞく)
　カードの裏を表示したいときには WRITEタグ を使ってください。FORMや[](大かっこ)を使えば、カードの裏には数字だけでなく文字も書き込めます。
    使える組み合わせリスト
  1. ( a )
    aが0以外か？
    aが0以外の時、1。0の時は0になる。
  2. ( ! a )
    aが0か？
    aが0以外の時、0。0の時は1になる。
  3. ( @ a )
    0～aまでの乱数を返す。
    括弧の値はaを最大とする乱数。
  4. ( a ? b )
    aとbが等しいか？
    aとbが等しい時に括弧の値は1になる。そうでないときは0。
    ここでは言葉を[ ](大かっこ)でくくると文字を比べらる。
  5. ( a = b )
    aとbを同じにする。
    aにbを代入する。括弧の値はa
    左の値が[ ]で囲ってあり、右がカードの名前だったときは
    [ ]の文字列がカードの裏に書かれる。
    右のカードにコピーされる。
    文字をコピーした場合には括弧の値は1
  6. ( a ^ b )
    aが0でないならbを実行する。
    aが0でない時にのみbを実行します。
  7. ( a | b )
    もしくは
    片方が0でない時に括弧の値は1になる。それ以外は0。
  8. ( a & b )
    かつ
    両方とも0でない時に括弧の値は1になる。それ以外は0。
  9. ( a > b )
    左が大きい
    左が大きい時に括弧の値は1になる。それ以外は0。
  10. ( a < b )
    右が大きい
    右が大きい時に括弧の値は1になる。それ以外は0。
  11. ( a + b )
    aとbを足す
    括弧の値はa+bの値
  12. ( a - b )
    aからbを引く
    括弧の値はa-bの値
  13. ( a * b )
    aとbをかける
    括弧の値はa*bの値
  14. ( a / b )
    aをbで割る
    括弧の値はa/bの値、bが0の時は0。
  15. ( a % b )
    aをbで割った余り。
    括弧の値はaをbで割った余り。
    最初からあるカード
  1. DNML_VERSION
     DNMLのヴァージョンは「DNML Version 2.15.03.12」の様に、四つの 数字に分かれています。
    DNML_VERSIONには「一番左の数字×100＋左から2番目の数字」です。
    「DNML Version 2.15.03.12」の場合は215です。
例
    　クイズゲームの例。
  1. 第一問
    <A HREF="" ALT="A." ANSWER="一正解">
    <A HREF="" ALT="B." >
    <A HREF="" ALT="C." >
    ・
    第二問
    <A HREF="" ALT="A." >
    <A HREF="" ALT="B." >
    <A HREF="" ALT="C." ANSWER="二正解">
    ・
    第三問
    <A HREF="" ALT="A." >
    <A HREF="" ALT="B." ANSWER="三正解">
    <A HREF="" ALT="C." >

    <QUESTION HREF="満点.dnml"
    　　　　　ANSWER="(3 ? (点数=(三正解+(二正解+一正解))))">
     全問正解なら、"満点.dnml"へ飛ぶ

    <QUESTION HREF="満点じゃない.dnml" ANSWER="(3 > 点数)">
     点数が3点以下なら"満点じゃない.dnml"へ飛ぶ

    <QUESTION HREF="一と二はできた.dnml" ANSWER="(一正解 & 二正解)">
     一問と二問が正解なら"一と二はできた.dnml"

    <QUESTION HREF="一か二はできた.dnml" ANSWER="(一正解 | 二正解)">
     一問か二問が正解なら"一か二はできた.dnml"

    点数は<WRITE SRC="点数">でした。
         WRITEタグでカードの裏の数字を表示できる。

    <QUESTION HREF="" ANSWER="(友好度 = 0 )">
    友好度を0にする。

    <QUESTION HREF="" ANSWER="(友好度 = (友好度 + (点数)))">
    点数が0点でなかったら友好度が1増える。

    <QUESTION HREF="" ANSWER="(友好度 = (友好度 + (1 < 点数)))">
    点数が一点より大きければ友好度が1増える。

    <QUESTION HREF="イベント.dnml" ANSWER="(友好度 > 3)">
    友好度が3より大きければイベント発生。

    <QUESTION ANSWER="(サイコロ=((@5)+1))">
    <WRITE SRC="サイコロ">
     (@5)は0～5迄の乱数が入ります。((@5)+1)で1を足すので
    "サイコロ"には 1～6迄の乱数が入る。

    <QUESTION ANSWER="((サイコロ > 5)^(メッセージ=[あなたの勝ちです]))">
    <WRITE SRC="メッセージ">
     サイコロで6を出したときのみ、「あなたの勝ちです」と表示されます。

    名字という名前の裏に折原と書く。
    <WRITE SRC="名前">と書くと折原と表示される。

    <EVENT ANSWER="(DNML_VERSION<215)">
    　　このブックはDNMLのヴァージョン2.15以上を使って下さい。
    　　<END>

    <QUESTION HREF="イベント.dnml" ANSWER="(好きな物?[焼きビーフン])">

カードの高度な使い方

　カードは名前を{}(中かっこ)で囲う事により、全てのタグの中で使う事が できます。
　中かっこの中にカードの名前を書くと、そこの部分をそのカードの 裏に書かれた値に書き換えます。
この置き換えはALIASの置き換えより後に行われます。
例
  1. 武器をえらんでください。
    <A HREF="" ALT="クリムゾン" ANSWER="(武器=[クリムゾン])">
    <A HREF="" ALT="デスクリムゾン" ANSWER="(武器=[デスクリムゾン])">
    <A HREF="" ALT="キングクリムゾン" ANSWER="(武器=[キングクリムゾン])">

    佐藤が現れた。どうする？
    <A HREF="" ALT="{武器}を使う" ANSWER="(メッセージ=[「おーのー」佐藤を倒した])">
    <A HREF="" ALT="逃げる" ANSWER="(メッセージ=[越前は逃げ出した])">
    <WRITE SRC="メッセージ">

    このサンプルは「DNMLBook\サンプル\card2.dnml」に入っています。
    一つ目の選択肢で「武器」という名前のカードの裏に、読者が選んだ武器の 名前が書かれます。
    二つめの選択肢では{武器}と書かれた部分を その裏に書かれた名前に置き換えます。
    実際の選択肢には読者が選んだ武器の名前が表示されます。
