画面に人物を表示させるタグです。ENTER(登場),ACT(画像の表示),EXIT(退場)が一組になっています。

ENTER(登場)
ACT(画像の表示)
EXIT(退場)

ENTERタグ

人物を登場させます。
キー
  1. NAME [省略不可]
    登場人物に名前を付けます。適当に好きな名前を付けてください。
    以後のACTタグ,EXITタグでこの名前を使います。
  2. ALIGN [省略時の値は"CENTER"]
    登場人物の立つ位置を指定します。
    CENTER(画面中央),LEFT(左),RIGHT(右), LEFTSIDE(左端にくっつける),RIGHTSIDE(右端にくっつける)が指定できます。

  3. VALIGN [省略時は"FLOOR"]
    登場人物の縦方向の位置を指定する。
    ROOF(画面の上端に付ける),FLOOR(下端に付ける),TOP(上), MIDDLE(中央),BOTTOM(下)が指定できます。
  4. EFFECT [くわしくはEFFECTキー参照]
    効果を付けて人物を表示します。
    EFFECTキーで説明します。
    ここで指定したEFFECTはこの人物に対する全てのACTに使われます。

  5. ALPHA [省略時の値は"100"]
    人物を半透明で表示したいときはこのキーを指定します。
    0が完全な透明、100がそのまま。
    ここで指定した不透明度はこのキャラクタ対する全ての
    ACTに影響します。

例
  1. <ENTER NAME="あかり" ALIGN="CENTER">
    "あかり"という名前のキャラクタを画面の中心に登場させます。 まだACT(演技)してないので、画面には何も表示されません。

ACTタグ
ENTER(登場)した人のグラフィックを表示します。
標準でBMP画像が読み込めます。それ以外の形式の画像を読み込みたい場合は PLUGINタグを使用してください。
キー
  1. SRC [省略不可]
    表示するファイル名を指定。
  2. FOLDER [省略時の値は"CURRENT"]
    表示するファイルのあるフォルダを指定。
  3. MODE [省略時の値は"WAIT"]
    "WAIT"だと、タグを実行したら、すぐグラフィックを表示します。
    MODEにPASSを指定するとすぐにグラフィックを表示しない。
    次にACT、BACKGROUND、EXITタグが実行されたときに同時に表示される。
  4. TOP [省略時の値はALIGNよりDNMLが決める]
    表示するグラフィックの上端の座標を指定。
  5. LEFT [省略時の値はALIGNよりDNMLが決める]
    表示するグラフィックの左端の座標を指定。
  6. WIDTH [省略時の値はグラフィックの幅]
    表示するグラフィックの幅を指定。 "100"の様に直接画像の幅を指定する事と
    (この場合、画像の幅は100[画素]となる)
    "200%"の様に割合でも指定できる。
    (この場合、画像の幅は元の大きさの2倍)
  7. HEIGHT [省略時の値はグラフィックの高さ]
    表示するグラフィックの高さを指定。
    指定の仕方はWIDTHと同じ。
  8. EFFECT [くわしくはEFFECTキー参照]
    効果を付けて人物を表示します。
    EFFECTキーで説明します。
  9. ALPHA [省略時はENTERで指定した値]
    人物を半透明で表示したいときはこのキーを指定します。
    0が完全な透明、100がそのまま。

    ファイル名で指定すると
    その画像がアルファチャンネルとなる。
    (ALPHAで指定した画像はモノクロに変換され、
    それがウィンドウの
    不透明度(いわゆるアルファチャンネル)となります。
    ALPHAで指定した画像の黒い部分は透明になります。
    白い部分は不透明で普通に表示されます。
    形式はDNMLで読める形なら何でもかまいません)

  10. SUBFOLDER [省略時の値はFOLDERと同じ]
    ALPHAで指定したファイルのあるフォルダを指定。

  11. TRANSPARENT [省略時の値はAUTO]
    画像の透明色を指定する。
    　　NONE
    　　　　透明色なし
    　　AUTO
    　　　　画像の一番左上の点とRGBで(255,0,255)の色を透明色にする。
    　　　　16色画像の場合は右上の点を透明色とします。(痕対策)
    　　"#ffffff"の様にHTML式で色を指定
    　　　　その色を透明色にする。
  12. PUT [省略時はSPACEタグの範囲を使う]
    人物画像の表情のみ変更したいときなどに使います。
    NAMEキーには既に登場している人物の名前を指定します。
    通常TOPやLEFTで指定した値は、SPACEタグ で指定した範囲にから計算されますが、この属性を指定するとその
    人物の画像が表示されている範囲を使います
例
  1. <ACT NAME="あかり" SRC="lvns3dat.pak\C0101.LF2" FOLDER="LVNS3">
    ENTERで登録した位置にC0101.LF2を表示します。
  2. <ACT NAME="マルチ" SRC="LVNS3DAT.PAK\c0619.lf2" FOLDER="LVNS3" TOP="136" LEFT="403">
    でマルチとエアホッケーできます(笑)。
  3. <ACT NAME="タイトル" SRC="title.bmp" TRANSPARENT="NONE">
    絵を透明色なしでそのまま表示
  4. <ACT NAME="あかり" SRC="lvns3dat.pak\C0101.LF2" FOLDER="LVNS3" MODE="PASS">
    <ACT NAME="志保" SRC="lvns3dat.pak\C0201.LF2" FOLDER="LVNS3">
    一行目にはMODE="PASS"が指定してあるので、すぐには表示されずに 二人の人物が同時に表示されます。
  5. <ACT NAME="表情" SRC="笑顔.bmp" PUT="ヒロイン">
    笑顔.bmpという画像が既に"ヒロイン"という名前の人物の上に表示されます。

EXITタグ

人物の退場。画面から人が消えます。
キー
  1. NAME [省略時の値は"ALL"]
    退場させたい人物のなまえを指定させます。
    ALLで全員退場。
  2. EFFECT [くわしくはEFFECTキー参照]
    効果を付けて人物を表示します。
    EFFECTキーで説明します。
    ここで指定したEFFECTはこの人物に対する全てのACTに使われます。
  3. MODE [省略時の値はすぐに退場]
    MODEにPASSを指定するとすぐに退場しない。
    次にACT、BACKGROUND、EXITタグが実行されたときに同時に退場します。
例
  1. <EXIT NAME="あかり">
    "あかり"という名前で登録したキャラを退場させます。
  2. <EXIT NAME="ALL">
    全員退場。
